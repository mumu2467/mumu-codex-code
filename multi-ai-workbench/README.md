# multi-ai-workbench · 多 AI 聚合工作台

把一条消息（文字 + 图片）**同时**投递给 DeepSeek / 豆包 / Kimi，并提供两种查看方式：

- **页面 1 · 三窗并发**：三列等宽聊天窗，各自独立流式输出、独立滚动、独立停止/清空/新会话。
- **页面 2 · 聚合对话**：单列 IM 风格，三家回复聚合在左侧同一气泡内，可切换、可并排对比、可投票采纳、可导出。

## 技术选型（一句话版）

**路线 A（Playwright 驱动三家真实网页版）为主 + 路线 B（官方 API）兜底**，两者实现同一套 `ChatAdapter` 接口，可运行时热切换。

> 三家 C 端网页版有 `X-Frame-Options` / CSP，且**同源策略**决定了 iframe 只能"看"不能"读"，因此必须由后端真实浏览器实例读写，前端通过 WebSocket 接收流式文本（可选叠加低帧率画面流）。
